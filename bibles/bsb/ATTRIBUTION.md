## Berean Standard Bible (BSB) — USFM Files

The USFM files in this directory contain the complete **Berean Standard Bible (BSB)**, version 5.2, comprising all 66 books of the Old and New Testaments.

### Source

- **Repository:** [BSB-publishing/bsb2usfm](https://github.com/BSB-publishing/bsb2usfm)
- **Release:** [v5.2](https://github.com/BSB-publishing/bsb2usfm/releases/tag/v5.2)
- **Asset:** `BSB_usfm.zip` (standard clean text, USFM format)
- **Website:** [bereanbible.com](https://bereanbible.com)
